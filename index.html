📊 구글 스프레드시트 연동

연동하면 새 의견이 작성일시 · 카테고리 · 작성자 · 내용 · 좋아요수 순서로 내 구글 시트에 자동 저장되고, 같은 링크(QR)로 들어온 모든 학생 기기의 칠판이 시트를 기준으로 실시간 동기화됩니다.

  1. 새 구글 스프레드시트를 만들고 확장 프로그램 → Apps Script를 엽니다.
  2. 기존 코드를 지우고 아래 Code.gs 코드를 붙여 넣은 뒤 저장합니다.
  3. 배포 → 새 배포 → 유형: 웹 앱을 선택합니다.
  4. 실행 사용자: 나, 액세스 권한: 모든 사용자로 설정하고 배포(권한 승인)합니다.
  5. 발급된 웹 앱 URL(…/exec)을 아래에 붙여 넣고 저장합니다.
  6. 연동 후 QR코드 공유의 링크에는 이 URL이 함께 담기므로, 학생들은 따로 설정할 필요가 없어요.
Code.gs
